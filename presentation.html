How It Works

📄 Step 1: Upload Portfolio

Upload your portfolio JSON file or use the sample portfolio to get started instantly.

🎯 Step 2: Select Analysis Type

Choose from 4 preset question types or write a custom query to analyze specific aspects.

🤖 Step 3: Multi-Agent Processing

The supervisor orchestrates agents: Portfolio Reader extracts data, Market Search enriches context, Report Writer generates analysis.

📊 Step 4: View & Export

View the professional report inline or download as PDF with type-specific naming.

📚 Step 5: Track History

Access your complete analysis history and re-generate previous reports with full caching support.

System Architecture

📄

Portfolio Reader Agent

Extracts and parses portfolio JSON files, structures holding data, calculates allocations and position metrics for comprehensive portfolio analysis.

🔍

Market Search Agent

✍️

Report Writer Agent

Uses OpenAI GPT-3.5-turbo to generate professional, formatted markdown reports with context-aware analysis and recommendations.

🎮

Supervisor Orchestrator

LangGraph-based coordinator managing agent workflow, data flow, error handling, and ensuring seamless multi-agent interaction.

Project Structure

portfolio_agent_project/
├── app.py                          # Main Streamlit application
├── agents/
│   ├── supervisor.py               # LangGraph supervisor orchestrator
│   ├── portfolio_agent.py           # Portfolio reading & analysis
│   ├── search_agent.py              # Market intelligence
│   └── writer_agent.py              # Report generation with type-aware prompts
├── utils/
│   └── pdf_generator.py             # Markdown to PDF conversion
├── portfolio_sample.json            # Sample portfolio data
├── requirements.txt                 # Python dependencies
└── .env                             # Environment variables (API keys)

Installation & Setup

# 1. Clone or navigate to the project
cd portfolio_agent_project

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate  # or: venv\Scripts\activate (Windows)

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up environment variables
# Create .env file with:
OPENAI_API_KEY=your_openai_key
TAVILY_API_KEY=your_tavily_key

# 5. Run the application
streamlit run app.py
